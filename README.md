# LLM Hedge Fund Group

ファンダメンタル分析を主軸にするヘッジファンドの仕事を、軽量または無料で使える LLM の分業でどこまで再現できるかを調べる実験用リポジトリです。既存の `modelctl` コマンドと GPT-luna を利用します。

実資金の運用、売買の自動執行、投資助言は対象外です。

## 実験の方針

企業の開示資料や業績、事業環境から投資仮説を作り、別の役割が根拠と反証を確認します。リスク担当は仮説の不確実性、集中、流動性、損失要因を点検します。単一モデルの結論をそのまま採用しない手順を試します。

想定する役割は次のとおりです。

| 役割 | 担当 |
| --- | --- |
| 調査 | 公開情報を集め、出典と時点を残す |
| アナリスト | 事業・財務・バリュエーションから仮説を作る |
| 反証担当 | 競合する説明や仮説が崩れる条件を探す |
| リスク担当 | 集中、流動性、下振れ要因、前提の弱さを確認する |
| 統括 | 意見の相違と未解決事項を整理し、実験結果を記録する |

## 評価すること

- 根拠を一次資料までたどれるか
- 事実、推定、意見を区別できるか
- 反証やリスク指摘が結論に反映されるか
- 使用モデルとコストに対して、分析の質がどの程度変わるか

収益率だけで判断せず、調査過程の再現性と誤りの見つけやすさも見ます。モデルの出力は検証対象であり、事実として扱いません。

## 公開リポジトリの扱い

API キー、認証情報、非公開資料、個人情報をコミットしないでください。ローカルの設定値は `.env`、非公開の入力や出力は `private/`、`data/private/`、`outputs/private/` に置きます。コミット前に差分を確認します。

## 現在の状態

目的と実験範囲を定めた段階です。役割間の入出力、使用データ、評価手順、実行方法はまだ確定していません。
