# １銘柄から始める実験サイクルの査読

査読日: 2026-09-26

## 判定

**条件付きで承認する。** 実在銘柄を使い、米国市場の開始前に判断を固定し、引け後に仮想損益と予測誤差を観測する設計は、将来の結果による検証ができる。外部研究チームが判断の質を主目的として評価する点にも賛成する。

修正が必要なのは、**１日の株価変動をファンダメンタル判断の正否や組織改革の根拠にしないこと**と、**判断時刻・仮想約定・評価期間を固定すること**である。短期の運用成績から能力を識別することは難しい。評価には運用結果だけでなく、その結果がどの判断工程から生じたかを見る必要がある。[CFA Institute: Investment Manager Selection](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/investment-manager-selection)、[Muralidhar: 投資判断の評価期間とノイズ](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2598476)

## 提案された５段階への査読

| 段階 | 判定 | 修正案 |
| --- | --- | --- |
| 1. 開場前に調査レポートとリターンを見て判断 | 承認 | 前日までの損益は状態情報として見せる。売買を強制せず、維持・縮小・見送りも有効な判断にする。DCF の事業前提は新しい事実か明示的な推定変更があるときに更新する。価格変動だけを理由に将来 FCF を書き換えない |
| 2. 米国市場開場 | 承認 | 判断と仮想注文を開場前の固定時刻で凍結し、次の通常取引時間の始値を仮想約定の基準にする。費用とスリッページの仮定も事前に固定する |
| 3. 閉場後にリターン算出 | 承認 | 始値から終値の新規判断分と、既存保有の前日終値から当日終値の損益を区別する。配当・株式分割・費用を反映し、銘柄の買い持ちと市場指数も並記する |
| 4. 外部チームが質を査読 | 修正して承認 | まず当日リターンを伏せて、出典、数値、DCF 前提、反証、リスク制約を採点する。その後に損益を開示し、予測と結果の差を記録する。組織・プロンプトの変更は日々の反応ではなく、蓄積した失敗パターンに対して版を上げて行う |
| 5. 反復 | 承認 | 翌営業日に戻る。ただし同じ予測を毎日「新しい投資判断」と数えず、判断 ID と評価期限を保持する |

通常取引時間は米東部時間 9:30〜16:00。休場日と夏時間を考慮する。[Nasdaq: 取引時間と休場日](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)

## 初回銘柄: Costco（NASDAQ: COST）

**実験対象として採用を推奨する。** 会員数・更新率・会費、既存店売上、店舗数、商品粗利率、賃金・設備投資など、開示された事業ドライバーを FCF に結び付けられる。会社は月次売上と四半期業績を公表するため、日次の価格観測に加えて、仮説の中身を更新するイベントもある。[Costco 投資家向け FAQ](https://investor.costco.com/resources/investor-faqs/)、[Costco イベント一覧](https://investor.costco.com/events-and-presentations/default.aspx?c=83830&p=irol-audioarchives)

2026-09-24 の会社発表は、2026年度の売上、会費収入、営業利益、営業キャッシュフローなどを含む。最初の判断ではこの発表を利用できるが、年度 10-K が後から出た場合は、開場前判断の資料へ遡及して混ぜない。[Costco 2026年度決算発表](https://investor.costco.com/news/news-details/2026/Costco-Wholesale-Corporation-Reports-Fourth-Quarter-and-Fiscal-Year-2026-Operating-Results/default.aspx)

これは銘柄への投資推奨ではない。１銘柄と現金だけの実験では、リサーチと判断のサイクルは検証できるが、分散したヘッジファンドのポートフォリオ構築能力はまだ検証できない。

## 必須の数値判断: 「なぜ」から DCF へ

最終レポートを単なる説明文で終えず、原資料から数値判断までを再計算可能にする。初回のモデルは事業ドライバー別の売上・利益から５年の FCFF を作り、企業価値から株式価値へ変換する。

```text
FCFF_t = EBIT_t × (1 - 税率_t) + D&A_t - 設備投資_t - 非現金運転資本増加_t
EV = Σ FCFF_t / (1 + WACC)^t + 継続価値 / (1 + WACC)^5
株式価値/株 = (EV + 非事業資産 - 有利子負債等) / 希薄化後株式数
```

FCFF と WACC による企業価値評価、継続価値、感応度分析は標準的な DCF の構成要素である。[CFA Institute: Free Cash Flow Valuation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)、[Damodaran: FCFF の定義](https://pages.stern.nyu.edu/~adamodar/pdfiles/dcfcf.pdf)

各前提には**数値・単位・根拠・判断時点・担当モデル・弱気／基準／強気の幅**を付ける。特に次を必須にする。

- 売上: 店舗数、既存店売上、会員数・更新率・会費、地域／商品構成をどう結び付けたか。
- FCF: 営業利益から税、減価償却、設備投資、運転資本へ至る橋渡し。過去の一時的な運転資本増減を恒常化しない。
- レバレッジ: 売上や粗利の変化が EBIT・FCF に何倍で効くかという**営業・FCF 感応度**と、純有利子負債、利払能力、リースの扱いを含む**財務レバレッジ**を別々に出す。
- 割引率と継続価値: WACC、長期成長率、継続価値が EV に占める割合、主要前提の感応度を表示する。
- 価格との比較: 判断時点の価格、DCF の１株価値レンジ、他の前提を固定して現在価格を正当化する暗黙の成長率／利益率、株価上昇・下落余地、配当を含む想定保有期間リターンを示す。

最終レポートの数値欄は、少なくとも以下を埋める。算出できない項目は推測値で埋めず、欠損理由を記し、投資判断を「保留」にする。

| 数値欄 | 表示内容 |
| --- | --- |
| 基準期 | 売上、EBIT、営業 CF、設備投資、報告 FCF、正規化 FCF |
| 予測 | ５年の売上・EBIT・FCFF、主要ドライバー別の寄与、弱気／基準／強気ケース |
| 資本・レバレッジ | 現金、有利子負債、リースの取扱い、純負債、利払能力、売上・粗利変化への FCF 感応度 |
| DCF | WACC、継続成長率、継続価値比率、１株価値レンジ、感応度表 |
| 市場との比較 | 凍結時点の株価、逆 DCF の暗黙前提、乖離率、配当込みの期間リターン、弱気時の損失 |
| 判断 | 仮想比率、リスク上限、採用／維持／縮小／見送り、反証条件、次回確認日 |

判断は「DCF が価格より高い」だけでは成立しない。反証条件、弱気ケースの損失、モデル誤差、代替機会、仮想ポジションの上限を通して、**採用・維持・縮小・見送り**のいずれかを理由とともに記録する。予測値と市場価格との差が研究上の焦点になる。[Morgan Stanley Investment Management: Probabilities and Payoffs](https://www.morganstanley.com/im/publication/insights/articles/article_probabilitiesandpayoffs.pdf?1759209040932=)

## ２つの時計を持つ運営案

**日次ループ（運用）**

1. 開場前に公開済み資料、直近価格、既存の仮想保有、前回判断の未解決事項を取得。資料公開時刻と判断時刻を記録する。
2. `modelctl` の Gemini Flash が数値・原文・期間を抽出し、計算コードが照合する。別コンテキストの Flash が反証を出し、GPT-luna が仮説と異論を統合する。リスク制約はコードで判定する。
3. レポートと仮想注文を凍結し、通常取引時間の次の始値で仮想約定。約定不能・価格欠損時のルールを事前に決める。
4. 引け後に仮想損益、買い持ちとの差、S&P 500 など市場との差を記録する。新しい開示があれば事業前提と反証条件を更新する。

**遅いループ（研究組織の改善）**

1. 外部研究チームが損益を伏せてレポート品質を評価し、原資料・数値・DCF・反証・リスクの誤りを分類する。
2. 翌日損益は補助情報として確認する。業績予測は次の月次売上・四半期決算、投資仮説は事前に定めた 20・60 営業日などの期間で評価する。
3. 繰り返した失敗にだけ、役割、プロンプト、モデル配置、検算ルールの変更案を作る。変更前の判断・予測・評価基準は保存し、変更後のケースにのみ新しい版を適用する。

当日リターンは**観測値**であって、日次の組織最適化の目的関数ではない。リターンを完全に見ないわけでもない。投資判断が事前に想定した事業イベントと市場の反応に整合したかを、複数の期間で確かめる。

## 拡大条件

最初の１銘柄で、公開資料から DCF・FCF 感応度・リスク審査・最終レポート・仮想判断・市場結果・事後査読まで１巡し、次回の更新でも同じ形式を保てたら対象を増やす。加えて、主要数値が原資料へ遡れること、計算が再現できること、判断時点より後の情報が混入していないこと、見送りを含む判断が記録されることを確認する。

その後は S&P 500 採用銘柄などへ段階的に広げる。過去検証に使う候補集合は**当時の構成銘柄**で作り、現在の構成銘柄を過去へ遡及させない。１銘柄での完走はワークフローの実行可能性を示すが、予測力や超過収益の証明にはならない。銘柄数を増やした段階で初めて、業種集中、共通ドライバー、相関、流動性を使ったポートフォリオ判断を本格的に評価できる。
