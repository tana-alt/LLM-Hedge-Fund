# Fundamental hedge fund の判断工程と本プロジェクトへの適用

調査日: 2026-09-26

## 結論

本プロジェクトで再現すべき中心は、LLM に「買い／売り」を言わせることではない。公開された原資料から検証可能な事実を取り出し、事業の因果モデル、将来シナリオ、市場価格に織り込まれた期待との差、反証条件、ポートフォリオ上のリスクへと変換する判断工程である。実務上のエッジは、資料の要約そのものではなく、**どの事実が将来キャッシュフローを動かすかを見極め、その見方が価格の示す期待と異なることを根拠付きで示せるか**にある。これは価格と価値の差を「variant perception」と捉える実務家の説明とも一致する。[Morgan Stanley Investment Management: Probabilities and Payoffs](https://www.morganstanley.com/im/publication/insights/articles/article_probabilitiesandpayoffs.pdf?1759209040932=)

ただし、同じ公開情報と似た LLM を誰もが使える以上、LLM の導入だけで超過収益は生まれない。本実験でまず検証できるのは、調査の速度、根拠の追跡可能性、反証の質、判断の一貫性が改善するかである。収益上の優位は別途、時点を固定した検証で確かめる必要がある。

## 実務では何をしているか

Fundamental な裁量運用の一般的な工程は、対象銘柄の選定、業界と事業の理解、業績予測、価値への変換、リスクを考慮したポートフォリオ構築、継続的な見直しである。[CFA Institute: Active Equity Investing—Strategies](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/active-equity-investing-strategies)

公開された具体例として Pershing Square は、投資候補ごとに通常２人のチームが初期調査を行い、会社・業界の資料、専門家への聞き取り、財務分析から事業の質と内在価値の初期見解を作る、と開示している。候補が基準を満たすと PM／CIO も調査し、投資チームで正式に議論する。この組織形態は１社の例であり、全ファンド共通の人員配置ではない。[Pershing Square Inc. S-1/A（SEC 提出書類）](https://www.sec.gov/Archives/edgar/data/2026053/000114036126014335/ny20040230x18_s1a.htm)

| 実務上の機能 | 判断に渡すもの | 本実験での対応 |
| --- | --- | --- |
| 調査担当 | 原資料、数値、出典、開示時点、未確認点 | 公開資料の取得と出典台帳。数値の確定はコードで再計算する |
| セクター／企業アナリスト | 事業ドライバー、競争、財務予測、仮説 | LLM が因果関係とシナリオを記述する |
| 反証担当 | 代替説明、弱い前提、仮説が崩れる観測値 | 元の結論を見せる前に独立して弱点を探させる |
| PM／投資会議 | 価格対価値、確率と損益、見送り理由 | GPT-luna が意見の不一致を含む判断メモをまとめる |
| リスク担当 | 集中、共通要因、流動性、下方シナリオ | ルール計算と LLM の定性レビューを分ける |
| トレーダー／運用事務 | 執行可能性、コスト、照合、記録 | 実売買は行わず、仮想判断の価格・時点・費用前提を記録する |

Point72 のアナリスト職務には、財務モデル、予測、バリュエーション、企業・業界調査、PM への投資提案が明記されている。同社のリスク開示では、リスク管理部門と委員会はポートフォリオ管理部門から独立し、リスクの計測・報告とハードリミットの執行を担う。これらは公開された職務・統制の例であり、各社の内部判断の質を直接示すものではない。[Point72 Analyst 募集要項](https://careers.point72.com/CSJobDetail?jobCode=LSI-0003484&jobName=equity-financial-analyst-japan&locale=English&location=Tokyo&retURL=/CSCareerSearch)、[Point72 Europe リスク開示](https://point72.com/wp-content/uploads/2023/09/MIFIDPRU-Public-Disclosure.pdf)

役割は「人数の再現」ではなく、異なる問いを通すための分業とする。同じモデルを複数回呼ぶだけでは独立した知見にならないため、反証担当には先に原資料と仮説の主要前提だけを与え、最終判断は後から見せる。

## 原データから投資判断まで

ここでいう「高次の情報」は数値上の次元数ではなく、個々の観測値を因果関係と意思決定の文脈に置いた情報を指す。工程ごとに、入力・変換・失われた情報を残す。

| 段階 | 入力例 | 出力する情報 | 確認すべき誤り |
| --- | --- | --- | --- |
| 1. 原資料 | 10-K/10-Q/8-K、決算説明、価格、業界統計 | URL、公開日時、対象期間、原文位置、単位 | 古い資料、期間混同、資料の公開前利用 |
| 2. 原子事実 | 売上、店舗数、継続率、粗利率、設備投資、借入条件 | 出典に紐づく数値と定義 | 会計定義、連結範囲、調整後数値の混同 |
| 3. 事業ドライバー | 原子事実の時系列と経営側の説明 | 数量×単価、顧客数×継続率、マージン、再投資の因果モデル | 相関を因果と誤認、単発要因を恒常化 |
| 4. 見通し | ドライバーと競合・業界の情報 | 強気・基準・弱気の前提、FCF／価値の幅 | 点推定への過信、主要前提の隠蔽 |
| 5. 市場との差 | 同日時点の価格、公開予想があればその値 | 価格を説明する暗黙の成長・利益率と自分の想定との差 | 「良い会社」を「割安」と取り違える |
| 6. 判断 | 差の根拠、反証条件、下方損失、他候補との比較 | 仮想的な採用／見送り／保留と再確認条件 | 既存ポートフォリオとの重複、流動性、費用の無視 |

SEC の EDGAR API は提出履歴と標準化された XBRL 財務数値を無料で提供する。ただし標準タグの集計だけでは企業固有の KPI や注記の文脈が落ちるため、原文との突き合わせが必要である。[SEC: EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

### 具体例: Costco の 2024 年開示をどう読むか

同社の 2024 年 10-K には、有料会員 7,620 万、世界の更新率 90.5%、会費収入 48.28 億ドル、純売上高 2,496.25 億ドルが記載されている。会費収入は前年比 5% 増だが、１週少ない会計年度だったことや会員の新規加入・上位会員への移行も同社は説明している。[Costco 2024 Form 10-K](https://www.sec.gov/Archives/edgar/data/909832/000090983224000049/cost-20240901.htm)

原子事実を「会員数・更新率・会員構成・会費単価が会費収入を動かす」というモデルに変えられる。しかし、更新率が高いというだけで買い判断にはならない。次に必要なのは、各ドライバーの将来レンジ、競争や賃金上昇がキャッシュフローに与える影響、現在の価格が要求する成長率である。価格との比較が欠ければ、事業の質を説明しただけで投資上のエッジは示せない。

### 実際の投資メモに見える「差」と「実現経路」

Third Point の 2024 年第４四半期の投資家レターは、Brookfield について運用資産と成長余地を述べたうえで、同社株式の翌年利益倍率を約 13 倍、比較対象の大手オルタナティブ運用会社を 20〜30 倍と置き、事業説明の改善を再評価のきっかけとした。これは同ファンド自身の見解であり、倍率の妥当性や実現を保証するものではない。判断の構造は「事業の収益力 → 比較可能な価格 → 市場の見落としという仮説 → 再評価が起きる条件」である。同レターの Siemens Energy でも、風力事業の過去損失と引当を切り分け、ガス・送電事業の受注残を将来利益へ結び付けている。[Third Point 2024 Q4 Investor Letter](https://assets.thirdpointlimited.com/f/166217/x/bc70b1b6dc/third-point-q4-2024-investor-letter_tpil.pdf)

本プロジェクトでは、この「差」と「実現経路」を投資メモの必須項目とする。カタリストがない長期の価値差もあり得るので、日時の確定したイベントを常に要求せず、何を観測したら市場の期待が変わるかを記録する。

### 企業リスクとポートフォリオリスクを分ける

企業の弱気シナリオが妥当でも、同じ金利・景気・セクター要因に依存する仮想ポジションを重ねれば全体の損失は増える。CFA Institute は銘柄分析とポートフォリオ構築を別の仕事とし、予想リターンとリスクの両方を用いて組入比率を決めると説明している。Third Point の開示でも、個別のファンダメンタル分析に加えて、集中、エクスポージャー、ベータ、流動性を扱う。[CFA Institute: Active Equity Investing—Portfolio Construction](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/active-equity-investing-portfolio-construction)、[Third Point 2022 Interim Report](https://assets.thirdpointlimited.com/f/166217/703a587e1b/1h-2022-financial-results.pdf)

初期実験では仮想ポートフォリオの１銘柄比率、業種比率、グロス／ネット・エクスポージャー、共通の下方シナリオ、出来高に対する仮想売買規模を、LLM の確信度と切り離して計算する。リスク制約への違反は統括役が文章で覆せないようにし、例外が必要なら実験設定の変更として記録する。実務の Form PF には、保有資産の流動化に要する期間、ストレス感応度、ドローダウンなどの項目もあるが、実売買をしない初期段階で全項目を模倣する必要はない。[SEC Form PF](https://www.sec.gov/files/formpf.pdf)

他ファンドの 13F を使う場合は、四半期末から最大 45 日遅れの提出で、ショートポジションは報告されない点に注意する。現在のポートフォリオや完全な判断根拠の代わりにはならない。[SEC: Form 13F FAQ](https://www.sec.gov/rules-regulations/staff-guidance/division-investment-management-frequently-asked-questions/frequently-asked-questions-about-form-13f)

## このプロジェクトの最小実験

**対象**: 最初は米国上場株の公開情報に限定し、銘柄と「その日に利用可能だった資料」の時点を固定する。実資金、売買の自動執行、非公開情報の収集は扱わない。

**１件の成果物**:

1. `source_manifest`: 原資料の URL、取得日、公開日、会計期間、使用箇所。
2. `facts`: 数値・単位・定義・出典位置・計算式。LLM 抽出後に機械的に検算する。
3. `driver_model`: 利益と FCF を動かす３〜５個の主要変数、その因果関係、未確認事項。
4. `thesis`: 価格に織り込まれた期待との差、強気／基準／弱気の前提、反証条件。
5. `risk_review`: 下方シナリオ、既存の仮想ポートフォリオとの重複、流動性、見送り条件。
6. `decision_record`: 仮想判断、判断時点、使えた情報、各役割の異論、再確認日。

**モデル配置の仮説**: `modelctl` で利用できる軽量・無料モデルを原資料抽出、別視点の反証、定型レビューに使う。GPT-luna は意見の対立と未解決点の統合に使う。モデル名の違いそのものを成果とみなさず、役割の切り方と検証可能性を比較する。数値計算、公開日時の判定、価格取得、ポートフォリオ制約は決定的なコードに任せる。

**比較**: 同じ資料、同じ判断時点、ほぼ同じ推論コストで、(A) 単一 LLM の一括分析、(B) 分業型の分析を比べる。最初の１件で入出力を固め、次に複数業種・複数時点のケースへ広げる。人が銘柄名と方式を伏せて、出典照合、数値誤り、重要ドライバー、反証の具体性、リスクの見落とし、判断の説明可能性を採点する。将来の株価や後日公開された資料を判断時点に混ぜない。価格成績を見る場合も、手数料・スプレッド・ベンチマークを別に記録する。小標本の成績から超過収益を主張しない。

**合格条件**: まず全ての主要主張が出典か明示された推定に紐づき、重要な数値の検算が通り、価格対価値の差と反証条件が明記されること。分業型が一括分析より高い評価を得るかは実験結果で判定する。満たさない場合は、役割を増やす前に、抽出、出典、前提、比較設計のどこで失敗したかを調べる。

## 適用できる範囲と限界

公開開示の継続的な追跡、数値の突合、仮説の反証、判断記録は低コストで再現しやすい。一方、実務の専門家ネットワーク、経営陣へのアクセス、非公開の取引条件、執行能力そのものは LLM の役割分担では再現できない。専門家への聞き取りや代替データには重要な非公開情報が混入するリスクもあり、初期実験では公開資料に絞る。[SEC 提出の投資顧問会社 Code of Ethics における Expert Network 方針](https://www.sec.gov/Archives/edgar/data/2093364/000119312526200854/d309175dex99r2.htm)

最大の失敗モードは、資料の要約が滑らかなだけで、価格に対する異なる見通しも、反証条件もないメモを「投資判断」と呼んでしまうこと。次の実装では、この２点を必須項目として扱う。
